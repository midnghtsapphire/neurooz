# Neurooz Documentation

This directory contains design, architecture, and planning documentation for the **Neurooz** platform — an ADHD-specific productivity and financial guardian app built on the Oz Engine™.

> **Source:** These documents were originally published in [midnghtsapphire/revvel-standards](https://github.com/midnghtsapphire/revvel-standards) (PR #2) and ported here for co-location with the codebase.
